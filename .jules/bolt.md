## 2026-09-01 - Batching Native Executable Arguments in PowerShell
**Learning:** In PowerShell, when cleaning up resources via external binaries (like deleting Git branches), looping and calling the binary inside `ForEach-Object` incurs an O(N) process spawning overhead. Spawning processes is relatively slow, especially on Windows where PowerShell is frequently used. PowerShell automatically expands arrays passed to native commands into separate arguments (e.g., passing an array of branch names to `git branch -D` passes them as `git branch -D branch1 branch2`), making it easy to safely batch operations and achieve O(1) process spawning overhead. If git encounters an error deleting a specific branch (e.g., because it is the currently checked-out active branch), it will still successfully process and delete the remaining branches in the array.
**Action:** When automating external command-line tools that accept multiple target arguments (like `git branch -D` or `rm`), always filter and collect the targets into a PowerShell array, then pass the array directly to a single invocation of the executable rather than calling it in a loop.
